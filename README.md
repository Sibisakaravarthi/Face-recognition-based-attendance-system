🧠 Face Recognition Based Attendance System
This project is a Python-based Face Recognition Attendance System that uses OpenCV and face_recognition to automatically detect and mark attendance of known individuals in real time. It captures live video feed from a webcam, recognizes faces from a trained dataset, and logs the attendance with timestamps.

📌 Features
🎥 Real-time face detection and recognition using OpenCV

✅ Marks attendance automatically when a registered face is detected

📁 Attendance saved in a CSV file with name and timestamp

👤 Easily train the system with new faces

🔐 Prevents duplicate entries on the same day

🛠️ Technologies Used
Python Flask framework
HTML, CSS, JavaScript
OpenCV
face_recognition (dlib wrapper)
NumPy
Pandas
